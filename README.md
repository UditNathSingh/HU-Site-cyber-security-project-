# HU Portal Clone - Security Awareness UI

🔗 **Live Demo:** [huroorkee.netlify.app](https://huroorkee.netlify.app/)

🚨 **Disclaimer: Educational Purposes Only** 🚨  
*This project is a strict frontend user interface demonstration built for cybersecurity awareness. It does not contain active credential-harvesting backend scripts, databases, or data-storage endpoints. It was designed to highlight network vulnerabilities and emphasize the importance of secure, authenticated login architectures.*

## 📌 Project Overview
A responsive frontend replica of the Haridwar University student portal. This project was developed to demonstrate how easily official interfaces can be visually cloned and to educate peers on the risks of phishing and credential harvesting on local networks.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure and form architecture.
* **TailwindCSS:** Utility-first styling for rapid, responsive design and pixel-perfect UI cloning.
* **JavaScript:** DOM manipulation and simulated client-side form validation.

## ✨ Features
* **Accurate UI Replication:** Recreates the layout, typography, and styling of the target portal using modern CSS utilities.
* **Responsive Design:** Adapts smoothly across desktop and mobile viewports.
* **Simulated Authentication:** Demonstrates frontend form handling without transmitting or storing sensitive data.
